# 05 — 完成错误处理、可访问性和最终验收

**What to build:** 工作区在真实流式聊天、发送失败、存储异常、键盘操作和移动端使用下能够稳定恢复。错误以内联方式展示并支持重试，不破坏已有 Message Snapshot；完整功能通过工程、视觉和可访问性验收。

**Blocked by:** 04 — 交付 Kimi 风格响应式天气工作区

**Status:** ready-for-agent

- [ ] 空名称或重复项目名称在输入框下显示错误，弹窗保持打开且布局不跳动
- [ ] 发送失败以内联消息显示，并提供明确的重试或关闭操作

- [ ] 空状态和错误状态都保留输入区
- [ ] 焦点环可见且使用洋红色，不改变控件尺寸
- [ ] 项目选择器、菜单、对话框和移动端抽屉支持键盘操作

- [ ] 错误、成功和选中态不只依赖颜色表达，并满足文字对比度要求
