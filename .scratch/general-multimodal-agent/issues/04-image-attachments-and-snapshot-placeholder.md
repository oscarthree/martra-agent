# 04 — 通用会话的图片附件与快照占位降级

**What to build:** 通用助手项目的会话可以发送图片：用户点击附件按钮或把图片拖进聊天区，在发送前看到附件队列并可移除，图片随文字一起作为一条消息发出，模型基于 base64 原图（不压缩）回答关于图片内容的问题，多轮对话可继续追问。天气项目的会话不出现任何附件入口。图片数据不进入 localStorage：持久化消息快照前，图片/二进制 content part 被替换为文本占位 part；页面刷新后历史里该位置显示"图片未保存到本地"语义的弱化占位文案，对话文字完整保留。存储配额失败时保留内存中的工作区状态并给出轻量提示。

**Blocked by:** 03 — 项目类型选择与会话 agent 路由

**Status:** done

- [x] 支持点击选择与拖放两种方式；发送前可见队列、可移除；图片与文本作为同一条用户消息发送
- [x] 图片以 CopilotKit 默认 base64 data URL 原图直发，不做前端压缩；全链路（AG-UI → `@ag-ui/mastra` → Mastra → Moonshot `image_url` part）无需补丁
- [x] 天气会话不渲染任何附件入口，既有发送/重试/快照行为无回归
