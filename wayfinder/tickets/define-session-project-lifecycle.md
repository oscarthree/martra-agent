# 定义会话与项目生命周期

- Type: `wayfinder:grilling`
- Parent map: [Kimi 风格天气工作区](../maps/kimi-style-weather-workspace.md)
- Status: closed
- Blocking: 左侧导航和顶部项目操作

## Question

确定新建会话、自动保存、首条消息生成标题、历史分组、会话重命名/删除、项目切换、项目删除后会话进入未分类，以及空项目和空历史状态之间的完整生命周期规则。

## Resolution

- 新建会话前自动保存当前会话，然后创建并切换到当前活动项目下的空会话。
- 没有发送过消息的空会话不显示在历史列表中；发送第一条消息后才进入历史。
- 第一条用户消息自动生成标题，默认取去除换行后的前 24 个字符；用户可以手动重命名。
- 点击历史会话时，切换到目标会话并通过 `CopilotChatView` 加载其消息快照。
- 切换活动项目不会移动当前会话；当前会话保持原项目归属，后续新建会话进入新的活动项目。
- 新建项目后立即切换到新项目，并创建一个空会话。
- 删除项目时不删除其中的会话，所有会话移动到未分类状态。
- 删除当前项目后优先选中剩余项目列表中的第一个项目；如果没有剩余项目，创建并选中默认项目“天气助手”。
- 删除当前会话后优先打开同一项目中最近更新的其他会话；如果没有其他会话，则创建一个新的空会话。
- 历史按“今天、昨天、更早”分组，每组按更新时间倒序排列，并保留跨项目查看能力。
- 当前项目没有会话时，显示天气助手欢迎内容和推荐问题，不创建示例历史。
- 未分类会话保持未分类，不因为活动项目变化而自动归属项目；项目移动属于显式操作。
- 项目重命名确认后立即保存，并同步更新顶部项目选择器和左侧项目列表。
- 删除项目和删除会话都需要应用内确认，避免误操作。
