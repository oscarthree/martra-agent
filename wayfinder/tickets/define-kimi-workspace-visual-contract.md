# 定义 Kimi 风格工作区视觉契约

- Type: `wayfinder:prototype`
- Parent map: [Kimi 风格天气工作区](../maps/kimi-style-weather-workspace.md)
- Status: closed
- Blocking: 前端布局与响应式实现

## Question

通过一个低成本视觉原型确定桌面端约 240px 侧栏、顶部项目上下文栏、消息区、输入区、项目选择器、新建项目弹窗、空状态和移动端抽屉的具体层级、尺寸、颜色、间距、焦点态和错误态；同时明确哪些 Kimi 风格细节保留、哪些调整为 Weather Copilot 品牌。

## Resolution

### Layout

- 桌面端采用 Variant A 的宽侧栏基础，吸收 Variant C 的项目优先分区。
- 侧栏宽度为约 `240px`，不采用 Variant C 的 `330px`，也不采用 Variant B 的纯图标侧栏。
- 侧栏顺序为品牌标识、新建会话、工作区导航、我的项目、最近会话和底部本地工作区状态。
- 顶部保留项目上下文选择器；主聊天内容最大宽度约 `780px`。
- 顶部栏高度约 `64px`，桌面端内边距约 `24px`。

### Responsive behavior

- `720px` 以下进入移动布局，桌面侧栏隐藏。
- 移动端通过顶部菜单按钮打开宽度为 `min(280px, 86vw)` 的抽屉。
- 抽屉包含品牌、项目、会话历史和最近会话；点击遮罩或选择导航项后关闭。
- 移动端顶部栏高度约 `60px`，项目上下文选择器继续可见。
- 移动端不使用 Variant B 的纯图标侧栏。

### Brand and color

- 保留浅色工作区、轻边框、紧凑导航、顶部上下文栏和克制留白等 Kimi 风格布局语言。
- 不复制 Kimi 的 Logo、品牌名称、专属图标、颜色体系或文案。
- Weather Copilot 使用自己的品牌标识和天气内容。
- 主强调色使用克制的洋红色：`#C43D86`；悬停色为 `#A83270`，浅背景为 `#F9EAF2`，焦点环为 `rgba(196, 61, 134, 0.22)`。
- 洋红色用于发送按钮、选中态、焦点态、链接和主要确认按钮；天气状态继续使用蓝色、橙色和绿色等辅助色。
- 本轮只实现浅色主题，不实现深色模式、主题切换或用户自定义配色。

### Project selector and dialogs

- 项目选择器使用顶部下拉菜单，不使用独立页面或大型弹窗。
- 菜单包含当前项目、其他项目、未分类、新建项目，以及当前项目的重命名和删除操作。
- 桌面端菜单锚定在选择器下方；移动端可使用接近底部的操作面板。
- 新建项目使用轻量居中弹窗，包含名称输入框、取消和创建操作。
- 空名称或重复名称时，错误提示显示在输入框下方，弹窗保持打开。
- 创建成功后关闭弹窗，切换到新项目并创建空会话。

### States and feedback

- 空项目或空会话显示天气助手欢迎内容和推荐问题，不创建示例历史。
- 空状态和错误状态都保留输入区。
- 焦点环使用洋红色，但不改变控件尺寸。
- 项目名称错误预留固定提示空间，避免弹窗布局跳动。
- 发送失败以内联消息显示，并提供重试操作；不使用遮挡聊天区的全屏错误页。
- 存储失败使用轻量提示，同时保留当前内存中的工作区状态。
- 错误提示使用深红色或暖红色，不使用洋红色，避免与正常操作混淆。
- 删除项目和删除会话使用确认弹窗。

### Accessibility and motion

- 所有图标按钮提供可访问名称和悬停提示。
- 项目选择器、项目菜单和弹窗支持键盘操作。
- 洋红色不单独承担信息含义；错误、成功和选中态同时使用文字、图标或结构差异表达。
- 正常文字与背景满足可读性对比度，键盘焦点环始终可见。
- 移动端抽屉打开时将焦点限制在抽屉内，关闭后焦点返回菜单按钮。
- 页面首次加载、抽屉、菜单和弹窗使用克制的功能性过渡；开启“减少动态效果”时关闭非必要动画。
